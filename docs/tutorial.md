## 준비하기

### 1단계: Inkscape 설치 확인

Inkscape가 설치되어 있는지 확인합니다.

```bash
inkscape --version
```

없다면 [inkscape.org](https://inkscape.org)에서 다운로드하세요.

**필요 버전:** 1.0 이상

---

### 2단계: 템플릿 다운로드

프로젝트를 로컬에 다운로드하거나 clone합니다.

```bash
git clone <repository-url>
cd test3
```

---

### 3단계: 참조 사진 준비

작업할 석기의 사진을 준비합니다:

- **파일 형식:** JPG, PNG (권장: JPG)
- **해상도:** 300 DPI 이상 권장
- **촬영:** 평면, 측면, 단면 뷰
- **배경:** 단색 배경, 스케일 포함

참조 사진을 `refs/sample_lithics/` 폴더에 저장합니다.

---

## 프로젝트 시작

### 4단계: 템플릿 열기

Inkscape에서 템플릿을 엽니다:

**방법 1: GUI**
1. Inkscape 실행
2. **파일 → 열기** (Ctrl+O)
3. `templates/lithic_min.svg` 선택

**방법 2: 명령줄**
```bash
inkscape templates/lithic_min.svg
```

---

### 5단계: 새 파일로 저장

원본 템플릿을 보존하기 위해 새 이름으로 저장합니다:

1. **파일 → 다른 이름으로 저장** (Shift+Ctrl+S)
2. 파일명 입력:
   ```
   유적명_유물번호_날짜.svg
   예: jeonggok_JG2024-001_20250115.svg
   ```
3. 위치: 작업 폴더 선택
4. **저장** 클릭

---

### 6단계: 레이어 패널 열기

레이어를 관리하기 위해 레이어 패널을 엽니다:

- **레이어 → 레이어 및 객체** (Shift+Ctrl+L)

오른쪽에 레이어 패널이 나타납니다. 10개 레이어를 확인하세요:

```
01_OUTLINE
02_SCARS
03_RIPPLES
04_CORTEX
05_SECTION
06_LINKS
07_SYMBOLS
08_LABELS
09_LEGEND
10_GUIDES
```

---

### 7단계: 템플릿 안내문 삭제

중앙의 안내 텍스트를 선택하고 삭제합니다:

1. **선택 도구** (S) 활성화
2. 안내 텍스트 클릭하여 선택
3. **Delete** 키 누르기

---

### 8단계: 참조 사진 배치

`10_GUIDES` 레이어에 참조 사진을 배치합니다:

1. 레이어 패널에서 **10_GUIDES** 클릭하여 활성화
2. **파일 → 가져오기** (Ctrl+I)
3. 참조 사진 선택 (예: `refs/sample_lithics/lithic_01.jpg`)
4. **가져오기** 클릭
5. 사진 크기 및 위치 조정:
   - **선택 도구** (S)로 사진 선택
   - 모서리를 드래그하여 크기 조정
   - Ctrl 키를 누른 채 드래그하면 비율 유지

---

### 9단계: 참조 사진 투명도 조정

작업하기 쉽도록 투명도를 낮춥니다:

1. 참조 사진 선택
2. 화면 하단의 **불투명도** 슬라이더를 50% 정도로 조정
   - 또는 우클릭 → **객체 속성** → **불투명도** 50%

---

### 10단계: 참조 사진 잠금

실수로 이동하지 않도록 잠급니다:

1. 참조 사진 선택
2. 우클릭 → **잠금**
   - 또는 레이어 패널에서 자물쇠 아이콘 클릭

---

## 외곽선 그리기

### 11단계: 01_OUTLINE 레이어 선택

1. 레이어 패널에서 **01_OUTLINE** 클릭

---

### 12단계: 베지어 도구 선택

외곽선을 그리기 위해 베지어 도구를 선택합니다:

- **도구 상자**에서 **베지어 도구** 클릭
- 또는 단축키 **B** 누르기

---

### 13단계: 선 스타일 설정

외곽선 스타일을 설정합니다:

**방법 1: 스타일 참조 사용 (권장)**
1. 새 Inkscape 창에서 `styles/line_styles.svg` 열기
2. `style-outline` 샘플 선택 및 복사 (Ctrl+C)
3. 작업 파일로 전환, 붙여넣기 (Ctrl+V)
4. **스포이트 도구** (D)로 스타일 추출

**방법 2: 수동 설정**
1. **채우기 및 선** 패널 열기 (Shift+Ctrl+F)
2. **선 스타일** 탭 선택
3. 설정:
   - **너비:** 0.45 (단위: mm 선택)
   - **끝:** Round
   - **접합:** Round
4. **선 색상** 탭에서:
   - **RGB:** 0, 0, 0 (순수 검정)

---

### 14단계: 외곽선 그리기

참조 사진을 따라 외곽선을 그립니다:

1. 베지어 도구 (B) 활성화 확인
2. 시작점 클릭
3. 외곽을 따라 다음 점 클릭
4. 곡선 부분은 클릭 후 드래그하여 핸들 조정
5. 마지막 점에서 시작점을 다시 클릭하여 닫기

**팁:**
- 직선: 클릭만
- 곡선: 클릭 + 드래그
- 노드 수를 최소화하세요 (10-20개 정도)

---

### 15단계: 외곽선 다듬기

외곽선을 다듬습니다:

1. **노드 편집 도구** (N) 선택
2. 노드를 선택하고 위치 조정
3. 핸들을 드래그하여 곡선 조정
4. 불필요한 노드 삭제: 노드 선택 → Delete

**단순화:**
- **경로 → 노드 단순화** (Ctrl+L)

---

## 박리흔 추가

### 16단계: 02_SCARS 레이어 선택

1. 레이어 패널에서 **02_SCARS** 클릭

---

### 17단계: 박리흔 스타일 설정

박리흔용 선 스타일(0.30mm)을 설정합니다:

1. `styles/line_styles.svg`에서 `style-scar` 복사
2. 스포이트 도구 (D)로 스타일 적용

또는 수동 설정:
- **너비:** 0.30mm
- **색상:** #000000

---

### 18단계: 박리흔 경계선 그리기

박리 흔적의 경계를 그립니다:

1. 베지어 도구 (B) 선택
2. 박리흔 경계를 따라 선 그리기
3. 각 박리흔마다 별도의 선으로 그립니다

**주의:**
- 외곽선보다 얇은 선 (0.30mm)
- 박리 방향 고려

---

## 단면 그리기

### 19단계: 05_SECTION 레이어 선택

1. 레이어 패널에서 **05_SECTION** 클릭

---

### 20단계: 단면 위치 결정

단면은 **반드시 평면도의 우측**에 배치합니다:

```
[평면도]  [단면도]
  ←───────→
   수평 연결선
```

---

### 21단계: 단면 윤곽 그리기

1. 베지어 도구 (B) 선택
2. 선 스타일: 0.45mm (외곽선과 동일)
3. 단면 윤곽선 그리기

---

### 22단계: 단면 해칭 추가 (선택)

단면 내부에 해칭을 추가합니다:

1. 선 스타일: 0.20mm
2. 45도 각도로 평행선 그리기
3. 간격: 1-2mm

**자동 해칭:**
- 단면 영역을 만들고 템플릿의 해칭 패턴 적용 가능

---

## 연결선 추가

### 23단계: 06_LINKS 레이어 선택

1. 레이어 패널에서 **06_LINKS** 클릭

---

### 24단계: 수평 연결선 그리기

평면도와 단면도를 연결합니다:

1. **선 도구** (L) 또는 베지어 도구 (B) 선택
2. 선 스타일: 0.15mm
3. 평면도의 특징점에서 단면도의 대응점까지 **수평선** 그리기

**규칙:**
- 반드시 **수평** (대각선 금지)
- 짧고 간결하게
- 2-3개 정도면 충분

**팁:**
- Ctrl 키를 누른 채 드래그하면 수평/수직 고정

---

## 심볼 배치

### 25단계: 07_SYMBOLS 레이어 선택

1. 레이어 패널에서 **07_SYMBOLS** 클릭

---

### 26단계: 스케일바 배치

1. 새 창에서 `symbols/arrows_scalebar.svg` 열기
2. 적절한 스케일바 선택 (예: `scalebar-1cm-segmented`)
3. 복사 (Ctrl+C)
4. 작업 파일로 전환, 붙여넣기 (Ctrl+V)
5. 도면 하단에 배치

**⚠️ 중요:** 스케일바 크기를 조정하지 마세요!

---

### 27단계: 북화살표 배치

1. `symbols/arrows_scalebar.svg`에서 북화살표 선택
2. 복사 (Ctrl+C), 붙여넣기 (Ctrl+V)
3. 도면 우측 상단에 배치

---

## 라벨 및 범례

### 28단계: 08_LABELS 레이어 선택

1. 레이어 패널에서 **08_LABELS** 클릭

---

### 29단계: 유물 번호 추가

1. **텍스트 도구** (T) 선택
2. 적절한 위치 클릭
3. 유물 번호 입력 (예: "JG2024-001")
4. 폰트 설정:
   - **폰트:** Noto Sans CJK KR 또는 Liberation Sans
   - **크기:** 8pt
   - **색상:** #000000

---

### 30단계: 09_LEGEND 레이어 선택

1. 레이어 패널에서 **09_LEGEND** 클릭

---

### 31단계: 범례 작성

범례에 필수 정보를 포함합니다:

```
범례 (Legend)
─────────────
⊙⊙⊙ 코르텍스 (자연면)
▨▨▨ 단면
──── 연결선
↑N   북쪽
▬▬▬ 1cm

방향 체계: American Projection
유적: 전곡리
유물번호: JG2024-001
작성일: 2025-01-15
```

### 35단계: PDF로 내보내기

1. **파일 → PDF로 저장** (Ctrl+Shift+S)
2. 설정:
   - **PDF 버전:** PDF/X-1a
   - **✅ 텍스트를 패스로 변환**
   - **❌ 이미지 래스터화** (체크 해제)
   - **해상도:** 300 DPI
3. 파일명: `jeonggok_JG2024-001_20250115.pdf`
4. **저장**

---

### 36단계: PDF 확인

생성된 PDF를 열어서 확인합니다:

1. PDF 뷰어로 열기
2. 확대 (300%)하여 선 선명도 확인
3. 스케일바 크기 확인
4. 참조 사진이 없는지 확인
