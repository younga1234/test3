## 개요

### 목적

이 템플릿은 구석기 석기 실측 도면을 국제 관례에 맞춰 정확하고 일관되게 작성하기 위한 최소 구성 Inkscape 환경입니다.

### 핵심 원칙

1. **American Projection 준수**: 표준 방향 체계를 기본으로 합니다. 예외 시 도면 내 명시해야 합니다.
2. **정보 최대·잉크 최소**: 필요한 정보만 명확하게 표현하고 불필요한 장식을 배제합니다.
3. **표준 선굵기 준수**: 국제적으로 인정받는 선 두께 규격을 따릅니다.
4. **출판 품질**: 흑백 출력 시에도 선명하게 구분되는 고품질 도면을 작성합니다.

### 표준 선굵기 (mm)

| 요소 | 선굵기 | 용도 |
|------|--------|------|
| 외곽선 (outline) | **0.45mm** | 석기 외곽 윤곽선 |
| 박리흔 경계선 (scar) | **0.30mm** | 격지 제거 흔적 경계 |
| 파상선 (ripple) | **0.20mm** | 박리면 파상 무늬 (선택) |
| 연결선 (linking) | **0.15mm** | 뷰 간 수평 연결선 |
| 단면 윤곽 | **0.45mm** | 단면도 외곽선 |
| 단면 해칭 | **0.20mm** | 단면 내부 해칭 |
| 코르텍스 점묘 | **0.18mm** | 점 지름 |

## 시작하기

### 1. 템플릿 열기

```bash
# Inkscape에서 템플릿 열기
inkscape templates/lithic_min.svg
```

또는 Inkscape를 실행한 후:
- **파일 → 열기** → `templates/lithic_min.svg` 선택

### 2. 새 이름으로 저장

작업 시작 전 템플릿을 보존하기 위해 새 파일로 저장하세요:

- **파일 → 다른 이름으로 저장**
- 파일명 규칙 예시: `유적명_유물번호_YYYYMMDD.svg`
  - 예: `jeonggok_JG2024-001_20250115.svg`

### 3. 템플릿 안내문 삭제

작업 시작 전 템플릿 중앙의 안내문 텍스트를 선택하고 삭제(Delete)하세요.

## 작업 순서

### 단계별 작업 흐름

```
1. 참조 사진 배치 (10_GUIDES)
   ↓
2. 외곽선 그리기 (01_OUTLINE)
   ↓
3. 박리흔 경계선 (02_SCARS)
   ↓
4. 파상선 (03_RIPPLES, 선택)
   ↓
5. 코르텍스 점묘 (04_CORTEX)
   ↓
6. 단면 그리기 (05_SECTION, 우측)
   ↓
7. 연결선 (06_LINKS, 수평)
   ↓
8. 기호 배치 (07_SYMBOLS)
   ↓
9. 라벨 추가 (08_LABELS)
   ↓
10. 범례 작성 (09_LEGEND)
   ↓
11. 검증 (docs/checklist.md)
   ↓
12. 내보내기 (PDF/SVG)
```

**중요**: 각 단계는 순서대로 진행하는 것을 권장합니다. 레이어 순서가 시각적 계층을 결정합니다.

## 레이어별 작업 가이드

### 레이어 선택

화면 우측의 **레이어 패널**에서 작업할 레이어를 선택하세요.
- 패널이 보이지 않으면: **레이어 → 레이어 및 객체** (Shift+Ctrl+L)

### 1. `10_GUIDES` - 가이드 레이어

**용도**: 참조 사진 및 보조선 배치 (출력 시 숨김)

**작업**:
1. 석기 사진을 가져옵니다: **파일 → 가져오기** (Ctrl+I)
2. 사진을 실제 크기에 맞춰 조정합니다
3. 투명도를 50% 정도로 낮춥니다 (우클릭 → 객체 속성 → 불투명도)
4. 사진을 잠급니다 (우클릭 → 잠금)

**팁**:
- 평면도, 측면도, 단면도를 각각 적절히 배치하세요
- 스케일 참조를 위해 눈금자나 실제 크기 표시를 함께 촬영한 사진을 사용하세요
- 이 레이어는 출력 시 자동으로 숨겨지므로 최종 도면에 나타나지 않습니다

---

### 2. `01_OUTLINE` - 외곽선 레이어

**용도**: 석기의 외곽 윤곽선 그리기

**선굵기**: 0.45mm

**작업**:
1. **베지어 도구** (B) 선택
2. `styles/line_styles.svg`에서 외곽선 스타일 복사하여 적용하거나 수동 설정:
   - 선 두께: 0.45mm
   - 선 색상: #000000 (순수 검정)
   - 선 끝: round
   - 선 접합: round
   - 채우기: 없음
3. 참조 사진을 따라 외곽선을 그립니다

**팁**:
- 곡선은 부드럽게 연결하되, 각진 부분은 정확히 표현하세요
- 너무 많은 노드를 사용하지 마세요 (간결하게)
- 완성 후 **경로 → 노드 단순화** (Ctrl+L)로 최적화하세요

---

### 3. `02_SCARS` - 박리흔 경계선 레이어

**용도**: 격지 제거 흔적의 경계선 표시

**선굵기**: 0.30mm

**작업**:
1. 베지어 도구 (B) 선택
2. 선 스타일을 0.30mm로 설정 (외곽선보다 얇음)
3. 박리흔의 경계를 명확히 표시

**주의사항**:
- 박리흔은 외곽선보다 얇은 선으로 구분되어야 합니다
- 박리 방향을 고려하여 경계를 정확히 그리세요
- 중첩된 박리흔은 시간 순서를 고려하여 표현하세요

---

### 4. `03_RIPPLES` - 파상선 레이어 (선택)

**용도**: 박리면의 파상 무늬 표현 (선택 사항)

**선굵기**: 0.20mm

**작업**:
1. 베지어 도구 (B) 또는 **펜 도구** 선택
2. 선 스타일을 0.20mm로 설정
3. 박리면의 파상 패턴을 따라 곡선으로 표현

**언제 사용하나요?**
- 박리면의 특징적인 파상 패턴이 중요한 경우
- 타격 방향이나 박리 기술을 명확히 보여줄 필요가 있을 때
- 과도하게 사용하지 마세요 - "최소 잉크" 원칙 준수

---

### 5. `04_CORTEX` - 코르텍스 점묘 레이어

**용도**: 석기의 자연면(코르텍스) 표현

**점 크기**: 0.18mm 지름

**작업**:
1. **원 도구** (E) 선택
2. 지름 0.18mm의 원을 그립니다:
   - 툴바에서 정확한 크기 입력 (W: 0.18, H: 0.18)
3. 채우기: #000000 (검정), 선: 없음
4. 원을 복사하여 자연면 영역에 균일하게 배치

**방법**:
- **방법 1**: 수동 복사 (Ctrl+D)로 균일한 간격으로 배치
- **방법 2**: **편집 → 복제 → 타일 복제**로 패턴 생성
  - 행/열 설정: 간격 2mm 정도
  - 배치 후 불필요한 점 삭제
- **방법 3**: 점묘 패턴을 영역에 채우기로 적용 (템플릿 내 패턴 사용)

**팁**:
- 점 간격은 1.5~2.5mm 정도가 적절합니다
- 너무 조밀하거나 희박하지 않도록 주의하세요
- 자연면의 범위를 명확히 구분하세요

---

### 6. `05_SECTION` - 단면 레이어

**용도**: 석기의 세로 단면도 (우측 배치)

**선굵기**:
- 윤곽: 0.45mm
- 해칭: 0.20mm

**작업**:
1. **단면 위치**: 평면도의 **우측**에 배치 (국제 관례)
2. 단면 윤곽을 0.45mm 선으로 그립니다
3. 내부에 45도 해칭선을 0.20mm로 추가

**해칭 방법**:
- **방법 1**: 수동으로 선 그리기
  - 베지어 도구로 45도 선을 간격 1~2mm로 배치
- **방법 2**: 패턴 채우기
  - 템플릿의 `section-hatching-pattern` 사용
  - 단면 영역을 선택 → 채우기 → 패턴 선택

**주의사항**:
- 단면은 반드시 평면도의 **우측**에 배치하세요 (좌측 배치는 비표준)
- 단면의 스케일은 평면도와 동일해야 합니다
- 해칭 간격은 균일하게 유지하세요

---

### 7. `06_LINKS` - 연결선 레이어

**용도**: 평면도와 단면도를 연결하는 수평선

**선굵기**: 0.15mm

**작업**:
1. **선 도구** (L) 선택
2. 선 스타일을 0.15mm로 설정
3. 평면도와 단면도의 대응점을 **수평으로** 연결

**규칙**:
- 연결선은 반드시 **수평**이어야 합니다 (대각선 금지)
- 연결선은 짧고 간결하게 (과도하게 길지 않게)
- 동일 개체의 서로 다른 뷰(평면-단면)를 연결합니다
- 일반적으로 2~3개 정도의 연결선으로 충분합니다

**예시**:
```
[평면도] ────────── [단면도]
          ↑ 수평 연결선
```

---

### 8. `07_SYMBOLS` - 기호 레이어

**용도**: 스케일바, 북화살표, 방향 표시

**작업**:
1. `symbols/arrows_scalebar.svg` 파일을 엽니다
2. 필요한 심볼을 선택하고 복사 (Ctrl+C)
3. 작업 도면으로 돌아와 붙여넣기 (Ctrl+V)
4. `07_SYMBOLS` 레이어에 배치

**필수 심볼**:

#### 스케일바
- **위치**: 도면 하단 또는 범례 근처
- **선택**: 유물 크기에 따라 1cm, 2cm, 3cm 또는 5mm 스케일바 선택
- **중요**: 스케일바는 실제 측정 크기와 정확히 일치해야 합니다
  - 예: 1cm 스케일바 = 실제 10mm
  - 도면 배율이 1:1인지 확인하세요

#### 북화살표
- **위치**: 도면 우측 상단 또는 범례 영역
- **방향**: American projection에서는 일반적으로 상단이 북쪽
- 예외가 있을 경우 반드시 표시하고 설명하세요

#### 방향 화살표 (선택)
- 타격 방향이나 박리 방향을 나타낼 때 사용
- 헤르츠 콘 마커: 타격점과 충격 전파 방향 표시

---

### 9. `08_LABELS` - 라벨 레이어

**용도**: 텍스트 주석, 유물 번호, 방향 표기

**폰트**:
- 산세리프 (Noto Sans CJK KR, Liberation Sans, Arial)
- 크기: 7~9pt

**작업**:
1. **텍스트 도구** (T) 선택
2. 폰트 설정: Noto Sans CJK KR, 8pt
3. 필요한 라벨 추가:
   - 유물 번호 (예: JG2024-001)
   - 유적명 (예: 전곡리 유적)
   - 방향 표기 (필요시)
   - 특징 설명 (간결하게)

**원칙**:
- 라벨은 간결하고 명확하게
- 일관된 약어 체계 사용
- 도면을 가리지 않도록 적절히 배치
- 가독성을 위해 충분한 여백 확보

**약어 예시**:
- L: Length (길이)
- W: Width (너비)
- T: Thickness (두께)
- Ctx: Cortex (자연면)
- Prox: Proximal (근위부)
- Dist: Distal (원위부)

### 10. `09_LEGEND` - 범례 레이어

**용도**: 기호 설명, 방향 체계, 주석

**작업**:
1. 범례 영역을 도면 하단 또는 우측에 구성
2. 사용된 기호와 패턴 설명
3. 방향 체계 명시 (American Projection)
4. 필요한 주석 추가

**범례 포함 내용**:
- 스케일바 (1cm = 10mm)
- 북화살표 방향 설명
- 코르텍스 점묘 = 자연면
- 해칭 = 단면
- 선 종류별 의미 (필요시)
- 방향 체계: "American Projection"
- 작성자, 작성일 (선택)

**예시**:

```
│ ▬▬▬ 1cm                    │
├─────────────────────────────┤
│ 방향 체계: American         │
│           Projection        │
│ 유적: 전곡리                │
│ 유물번호: JG2024-001        │

```

## 선 스타일 적용

### 방법 1: 스타일 참조 파일에서 복사

1. `styles/line_styles.svg` 파일을 Inkscape에서 엽니다
2. 원하는 선 스타일 샘플을 선택합니다
3. 복사 (Ctrl+C)
4. 작업 도면으로 전환
5. 붙여넣기 (Ctrl+V)
6. 스타일을 추출할 객체 선택
7. **편집 → 스타일 복사** (Ctrl+Shift+C)
8. 스타일을 적용할 대상 선택
9. **편집 → 스타일 붙여넣기** (Ctrl+Shift+V)

### 방법 2: 스포이트 도구 사용

1. **스포이트 도구** (D) 선택
2. 샘플 선을 클릭 (스타일이 복사됨)
3. 스타일을 적용할 대상 객체 선택
4. 다시 스포이트 도구로 클릭하여 적용

### 방법 3: 수동 설정

1. 선을 선택
2. 화면 하단의 **채우기 및 선** 패널 열기 (Shift+Ctrl+F)
3. **선 스타일** 탭에서:
   - 너비: 원하는 mm 값 입력 (예: 0.45)
   - 끝: Round
   - 접합: Round
4. **선 색상** 탭에서:
   - RGB: 0, 0, 0 (순수 검정)

## 심볼 사용

### 심볼 가져오기

1. `symbols/arrows_scalebar.svg` 파일을 Inkscape에서 엽니다
2. 필요한 심볼 그룹을 선택합니다
3. 복사 (Ctrl+C)
4. 작업 도면으로 전환
5. `07_SYMBOLS` 레이어 선택
6. 붙여넣기 (Ctrl+V)
7. 적절한 위치로 이동

### 스케일바 배치 주의사항

**중요**: 스케일바는 실제 크기와 정확히 일치해야 합니다.

1. 스케일바를 붙여넣은 후 **크기 조정하지 마세요**
2. 도면 배율이 1:1인지 확인:
   - 참조 사진의 실제 크기와 도면의 크기를 비교
   - 필요시 참조 사진의 스케일을 조정
3. 1cm 스케일바는 정확히 10mm여야 합니다
   - 선택 → 객체 속성에서 너비 확인
   - 단위: mm

## 오류 사례와 수정 팁

### ❌ 오류 1: 과도한 음영 사용

**잘못된 예**:
- 그라디언트 채우기 사용
- 과도한 방사선 패턴
- 블러 효과

**올바른 방법**:
- 점묘와 해칭만 사용
- 명확하고 간결한 선으로 표현
- "정보 최대·잉크 최소" 원칙 준수

---

### ❌ 오류 2: 선굵기 혼용

**잘못된 예**:
- 외곽선과 박리흔 경계선이 같은 두께
- 임의의 선 두께 사용
- 선마다 다른 두께

**올바른 방법**:
- 표준 선굵기 엄수 (외곽 0.45, 박리흔 0.30, 파상선 0.20, 연결선 0.15)
- 레이어별로 일관된 선 스타일 적용
- `styles/line_styles.svg` 참조

---

### ❌ 오류 3: 비표준 방향 체계

**잘못된 예**:
- 방향 표시 없이 임의로 회전
- American projection 아닌 다른 체계 사용 (명시 없이)
- 단면을 좌측에 배치

**올바른 방법**:
- American projection 기본 사용
- 북화살표 반드시 표시
- 예외 시 범례에 명시
- 단면은 항상 우측에 배치

---

### ❌ 오류 4: 연결선 대각선 사용

**잘못된 예**:
```
[평면도]  ╲
           ╲
            ╲ [단면도]
```

**올바른 방법**:
```
[평면도] ────── [단면도]
         수평선
```

---

### ❌ 오류 5: 단면 좌측 배치

**잘못된 예**:
```
[단면도] [평면도]
```

**올바른 방법**:
```
[평면도] [단면도]
```

---

### ❌ 오류 6: 스케일바 크기 부정확

**잘못된 예**:
- 심볼을 붙여넣은 후 크기 조정
- 임의의 길이로 그리기
- 단위 표시 없음

**올바른 방법**:
- 심볼을 크기 조정 없이 그대로 사용
- 실제 측정과 정확히 일치하는지 확인
- 명확한 단위 표시 (cm 또는 mm)

## 내보내기

### PDF 내보내기 (권장)

PDF는 출판 및 보존에 가장 적합한 형식입니다.

1. **파일 → PDF로 저장** (Ctrl+Shift+S)
2. PDF 옵션 설정:
   - **PDF/X-1a** 또는 **PDF/A** 선택 (보존 표준)
   - **텍스트를 패스로 변환**: 체크 (글꼴 호환성)
   - **이미지 래스터화**: **체크 해제** (벡터 유지)
   - **해상도**: 300 DPI 이상 (래스터 요소가 있을 경우)
3. `10_GUIDES` 레이어 숨김 확인
4. 저장

### SVG 내보내기

벡터 형식 유지를 위한 SVG 내보내기:

1. **파일 → 다른 이름으로 저장**
2. 형식: **최적화된 SVG** 선택
3. 옵션:
   - **편집기 데이터 제거**: 체크 해제 (나중에 편집 가능)
   - **메타데이터 유지**: 체크
4. 저장

### PNG 내보내기 (웹 미리보기용)

1. **파일 → PNG로 내보내기** (Shift+Ctrl+E)
2. **페이지** 선택 (전체 페이지 내보내기)
3. **DPI**: 300 (고해상도) 또는 150 (웹용)
4. `10_GUIDES` 레이어 숨김 확인
5. 내보내기

### 내보내기 설정 파일

`export/pdf_settings.json` 파일에는 권장 설정이 저장되어 있습니다. Inkscape 명령줄 인터페이스를 사용할 경우 이 설정을 참조하세요.

```bash
# 명령줄 PDF 내보내기 예시
inkscape --export-type=pdf \
  --export-pdf-version=1.4 \
  --export-text-to-path \
  --export-filename=output.pdf \
  input.svg
```

## 문제 해결

### 문제: 선이 흐릿하게 보임

**원인**: 안티앨리어싱 또는 저해상도 미리보기

**해결**:
- **보기 → 표시 모드 → 윤곽선** (Ctrl+5)로 전환하여 정확한 선 확인
- 내보내기 시 300 DPI 이상 설정
- PDF로 내보내기 (벡터 유지)

---

### 문제: 스케일바와 실제 크기가 맞지 않음

**원인**: 참조 사진 크기 조정 오류 또는 스케일바 변형

**해결**:
1. 참조 사진의 실제 스케일 확인
2. 스케일바를 다시 붙여넣기 (변형 없이)
3. 객체 속성에서 스케일바 크기 확인 (1cm = 10mm)
4. 참조 사진을 스케일바에 맞춰 조정

---

### 문제: 레이어가 보이지 않음

**원인**: 레이어가 숨겨져 있거나 잠김

**해결**:
- **레이어 패널** 열기 (Shift+Ctrl+L)
- 레이어 옆의 눈 아이콘 확인 (보이기/숨기기)
- 자물쇠 아이콘 확인 (잠금/해제)

---

### 문제: PDF 내보내기 후 선이 너무 얇거나 두꺼움

**원인**: 단위 변환 오류

**해결**:
1. Inkscape 문서 속성 확인 (**파일 → 문서 속성**)
2. **기본 단위**: mm로 설정
3. **배율**: 1:1 확인
4. 다시 내보내기

---

### 문제: 글꼴이 다른 컴퓨터에서 깨짐

**원인**: 글꼴 미설치

**해결**:
- PDF 내보내기 시 "텍스트를 패스로 변환" 옵션 체크
- 또는 Noto Sans CJK KR 글꼴을 함께 배포
