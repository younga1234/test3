# 구석기 석기 일러스트 검증 체크리스트

**버전:** v1.0.0
**목적:** 국제 관례 준수 확인 및 출판 적합성 검증

---

## 사용 방법

도면 작성 완료 후, 아래의 모든 항목을 순서대로 확인하세요. 모든 체크박스에 ✓ 표시가 되어야 출판 및 제출이 가능합니다.

**확인 순서:**
1. 기본 구성 요소 확인
2. 방향 체계 및 배치 확인
3. 선 스타일 및 두께 확인
4. 심볼 및 라벨 확인
5. 내보내기 설정 확인
6. 최종 검토

---

## 1. 기본 구성 요소 확인

### 필수 요소 포함 여부

- [ ] **외곽선**: 석기의 외곽 윤곽선이 명확히 그려져 있음
- [ ] **박리흔 경계선**: 격지 제거 흔적 경계가 표시되어 있음
- [ ] **단면도**: 세로 단면이 포함되어 있음
- [ ] **연결선**: 평면도와 단면도가 연결되어 있음
- [ ] **스케일바**: 실제 크기를 나타내는 스케일바가 포함됨
- [ ] **북화살표**: 방향을 나타내는 북화살표가 표시됨
- [ ] **라벨**: 유물 번호 또는 식별 정보가 표기됨
- [ ] **범례**: 사용된 기호와 패턴에 대한 설명이 포함됨

### 선택 요소 (필요시)

- [ ] **파상선**: 박리면 파상 무늬가 표현됨 (필요한 경우)
- [ ] **코르텍스 점묘**: 자연면이 점묘로 표시됨 (자연면이 있는 경우)
- [ ] **방향 화살표**: 타격 방향이나 박리 방향이 표시됨 (필요한 경우)

---

## 2. 방향 체계 및 배치 확인

### American Projection 준수

- [ ] **American Projection 사용**: 표준 방향 체계를 따름
- [ ] **북화살표 표시**: 방향이 명확히 표시됨
- [ ] **예외 명시**: 비표준 방향 사용 시 범례에 명시됨

### 단면 배치

- [ ] **단면 우측 배치**: 단면도가 평면도의 **우측**에 배치됨 (좌측 배치 금지)
- [ ] **수직 배치**: 단면이 세로 방향으로 배치됨
- [ ] **스케일 일치**: 평면도와 단면도의 스케일이 동일함

### 연결선

- [ ] **수평 연결**: 연결선이 **수평**으로 그려져 있음 (대각선 금지)
- [ ] **짧고 간결**: 연결선이 과도하게 길지 않음
- [ ] **대응점 연결**: 평면도와 단면도의 정확한 대응점을 연결함
- [ ] **적절한 수량**: 연결선이 2~3개 정도로 적절함 (과도하지 않음)

---

## 3. 선 스타일 및 두께 확인

### 표준 선굵기 준수

아래 표의 규격과 일치하는지 확인하세요:

| 요소 | 표준 선굵기 | 확인 |
|------|-------------|------|
| 외곽선 (outline) | 0.45mm (0.35~0.5 범위) | [ ] |
| 박리흔 경계선 (scar) | 0.30mm (0.25~0.35 범위) | [ ] |
| 파상선 (ripple) | 0.20mm (0.18~0.25 범위) | [ ] |
| 연결선 (linking) | 0.15mm | [ ] |
| 단면 윤곽 | 0.45mm | [ ] |
| 단면 해칭 | 0.20mm | [ ] |
| 코르텍스 점묘 | 0.18mm (점 지름) | [ ] |

### 선 스타일 일관성

- [ ] **색상 일관**: 모든 선이 #000000 (순수 검정)임
- [ ] **선 끝 처리**: stroke-linecap이 round로 설정됨
- [ ] **선 접합 처리**: stroke-linejoin이 round로 설정됨
- [ ] **채우기 없음**: 선 객체에 불필요한 채우기가 없음

### 금지 요소 제거

- [ ] **그라디언트 없음**: 그라디언트 채우기가 사용되지 않음
- [ ] **블러 효과 없음**: 블러나 그림자 효과가 없음
- [ ] **컬러 사용 금지**: 검정(#000000) 외의 색상이 사용되지 않음
- [ ] **장식 요소 없음**: 불필요한 장식이나 패턴이 없음

---

## 4. 심볼 및 라벨 확인

### 스케일바

- [ ] **정확한 크기**: 스케일바가 실제 측정 크기와 정확히 일치함
  - 예: 1cm 스케일바 = 정확히 10mm
- [ ] **명확한 표시**: 스케일 단위가 명확히 표기됨 (cm 또는 mm)
- [ ] **적절한 위치**: 도면 하단 또는 범례 근처에 배치됨
- [ ] **가독성**: 스케일바가 다른 요소와 겹치지 않음

### 북화살표

- [ ] **명확한 표시**: 북쪽 방향이 명확히 표시됨
- [ ] **'N' 표기**: 북(North)을 나타내는 'N' 문자가 포함됨
- [ ] **적절한 위치**: 도면 우측 상단 또는 범례 영역에 배치됨

### 라벨 및 텍스트

- [ ] **폰트 규격**: 산세리프 폰트 사용 (Noto Sans CJK KR, Liberation Sans 등)
- [ ] **크기 적절**: 7~9pt 크기 범위 내
- [ ] **가독성**: 텍스트가 명확하게 읽힘
- [ ] **일관성**: 약어와 표기 방식이 일관됨
- [ ] **필수 정보 포함**: 유물 번호 또는 식별 정보가 포함됨

### 범례

- [ ] **기호 설명**: 사용된 모든 기호와 패턴이 설명됨
- [ ] **방향 체계 명시**: "American Projection" 명시됨
- [ ] **적절한 위치**: 도면을 가리지 않는 위치에 배치됨
- [ ] **완전성**: 필요한 모든 정보가 포함됨

---

## 5. 코르텍스 및 패턴 확인

### 코르텍스 점묘 (자연면이 있는 경우)

- [ ] **점 크기**: 점 지름이 0.18mm로 일정함
- [ ] **간격 균일**: 점 간격이 1.5~2.5mm로 균일함
- [ ] **밀도 적절**: 너무 조밀하거나 희박하지 않음
- [ ] **영역 명확**: 자연면의 범위가 명확히 구분됨

### 단면 해칭

- [ ] **각도 일정**: 해칭선이 45도 각도로 일정함
- [ ] **간격 균일**: 해칭 간격이 1~2mm로 균일함
- [ ] **선 두께**: 해칭선이 0.20mm로 일정함
- [ ] **범위 정확**: 단면 영역만 해칭됨

- [ ] **04_CORTEX**: 코르텍스 점묘 레이어 존재 (사용 시)

## 7. 내보내기 설정 확인

### PDF 내보내기 (권장)

- [ ] **PDF/X 또는 PDF/A**: 보존 표준 형식 사용
- [ ] **텍스트를 패스로 변환**: 글꼴 호환성 확보
- [ ] **벡터 유지**: 이미지 래스터화 비활성화
- [ ] **해상도**: 300 DPI 이상 (래스터 요소가 있을 경우)
- [ ] **가이드 레이어 제외**: `10_GUIDES` 레이어가 출력에서 제외됨

### 파일 이름 규칙

- [ ] **명확한 파일명**: 유적명_유물번호_날짜 형식
  - 예: `jeonggok_JG2024-001_20250115.pdf`
- [ ] **버전 관리**: 필요시 버전 번호 포함

## 8. 최종 품질 검토

### 시각적 검토

- [ ] **명확성**: 모든 요소가 명확히 구분됨
- [ ] **간결성**: 불필요한 요소가 없음 ("최소 잉크" 원칙)
- [ ] **균형**: 도면 배치가 균형 잡혀 있음
- [ ] **가독성**: 흑백 출력 시에도 모든 요소가 명확히 보임

### 정확성 검토

- [ ] **실측 대비**: 도면이 실제 유물과 일치함
- [ ] **비율 정확**: 모든 부분의 비율이 정확함
- [ ] **스케일 확인**: 스케일바로 측정 시 실제 크기와 일치함

### 표준 준수

- [ ] **국제 관례**: 국제 구석기 석기 도면 관례를 따름
- [ ] **일관성**: 동일 프로젝트/출판물 내 다른 도면과 스타일이 일관됨
- [ ] **출판 적합**: 학술지 제출 기준을 충족함
