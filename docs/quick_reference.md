# 빠른 참조 카드 (Quick Reference)

**구석기 석기 일러스트 Inkscape 최소 템플릿 v1.0.0**

---

## 📐 표준 선굵기

| 용도 | 선굵기 | CSS 클래스 |
|------|--------|------------|
| **외곽선** | 0.45mm | `.outline` |
| **박리흔** | 0.30mm | `.scar` |
| **파상선** | 0.20mm | `.ripple` |
| **연결선** | 0.15mm | `.linking` |
| **단면 윤곽** | 0.45mm | `.section-outline` |
| **단면 해칭** | 0.20mm | `.section-hatching` |
| **코르텍스 점** | 0.18mm ∅ | `.cortex-stipple` |

---

## 📋 레이어 순서

```
10. 10_GUIDES      (참조 사진, 비출력) 👁️‍🗨️
 9. 09_LEGEND      (범례)
 8. 08_LABELS      (라벨)
 7. 07_SYMBOLS     (스케일바, 북화살표)
 6. 06_LINKS       (연결선)
 5. 05_SECTION     (단면, 우측)
 4. 04_CORTEX      (코르텍스 점묘)
 3. 03_RIPPLES     (파상선, 선택)
 2. 02_SCARS       (박리흔)
 1. 01_OUTLINE     (외곽선)
```

---

## ✅ 필수 규칙

| 규칙 | 준수 사항 |
|------|----------|
| 방향 | American Projection (예외 시 명시) |
| 단면 위치 | 반드시 **우측** (좌측 ❌) |
| 연결선 | 반드시 **수평** (대각선 ❌) |
| 색상 | **#000000** (순수 검정만) |
| 스케일바 | 크기 조정 **금지** (정확성 유지) |
| 장식 | 그라디언트, 블러, 컬러 **금지** |

---

## 🎨 작업 순서 (10단계)

```
1. 참조 사진 배치 → 10_GUIDES
2. 외곽선 그리기 → 01_OUTLINE (0.45mm)
3. 박리흔 경계 → 02_SCARS (0.30mm)
4. 파상선 (선택) → 03_RIPPLES (0.20mm)
5. 코르텍스 점묘 → 04_CORTEX (0.18mm)
6. 단면 그리기 → 05_SECTION (우측, 0.45mm)
7. 연결선 → 06_LINKS (수평, 0.15mm)
8. 기호 배치 → 07_SYMBOLS
9. 라벨 추가 → 08_LABELS (7-9pt)
10. 범례 작성 → 09_LEGEND
```

## 📦 심볼 사용

### 스케일바
- `scalebar-1cm-segmented` (10mm)
- `scalebar-2cm-segmented` (20mm)
- `scalebar-3cm-segmented` (30mm)
- `scalebar-5mm-segmented` (5mm)

⚠️ **크기 조정 금지!** 복사 후 그대로 사용

### 북화살표
- `north-arrow-simple` (단순형)
- `north-arrow-filled` (채움형)
- `north-arrow-compass` (나침반형)

## 💾 내보내기 설정

### PDF (권장)
```
형식: PDF/X-1a 또는 PDF/A
옵션:
  ✅ 텍스트를 패스로 변환
  ❌ 이미지 래스터화 (벡터 유지)
  ✅ 해상도 300 DPI 이상
  ✅ 10_GUIDES 레이어 숨김
```

### 파일명 규칙
```
유적명_유물번호_날짜.pdf
예: jeonggok_JG2024-001_20250115.pdf
```

## 🚨 흔한 오류

| 오류 | 해결 |
|------|------|
| 선이 너무 두꺼움 | 표준 선굵기 확인 (0.45/0.30/0.20/0.15mm) |
| 단면이 좌측에 | 우측으로 이동 |
| 연결선이 대각선 | 수평으로 다시 그리기 |
| 스케일바 크기 틀림 | 심볼을 크기 조정 없이 재배치 |
| 색상이 회색 | #000000 (순수 검정) 사용 |
| PDF에서 선 흐림 | 래스터화 끄기, 벡터 유지 |
